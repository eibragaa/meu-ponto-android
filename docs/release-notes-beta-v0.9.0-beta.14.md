# Meu Ponto Beta — v0.9.0-beta.14

## Novidades

- **Lançar ponto manual:** opção "Digitar manualmente" para registrar data e horários
  sem precisar de foto (ideal para ponto web ou comprovante esquecido).
- **Espelho de Ponto em PDF:** tabela A4 consolidada com todas as batidas do dia,
  total, saldo do período e campo de assinatura — pronta para o RH.
- **Canhotos em PDF:** exporte apenas os comprovantes individuais, agora também em
  cartões vetoriais para registros manuais sem foto.
- **Intervalo inteligente:** ao sair para o almoço, o card mostra "Em intervalo" com
  horário de volta sugerido e previsão de saída.

## Correções

- Backup passa a preservar registros manuais sem imagem.
- A verificação de atualização respeita 1x ao dia (ou ao abrir o app).

## Observações

- Versão de teste com auto-atualizador integrado (APK `-updater`).
- Nenhuma mudança de banco de dados: atualização direta sobre a versão anterior.
