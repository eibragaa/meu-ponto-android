# Política de Privacidade — Meu Ponto

_Última revisão: 16 de outubro de 2026_

O Meu Ponto é um aplicativo pessoal para digitalizar, organizar e exportar comprovantes.

## Dados processados

As imagens dos comprovantes, textos reconhecidos por OCR, datas e horários são armazenados no espaço privado do aplicativo no aparelho do usuário. O OCR é executado localmente no dispositivo para preencher os dados do comprovante.

O aplicativo não vende dados pessoais, não usa os comprovantes para publicidade e não envia automaticamente os documentos para um servidor próprio.

## Exportação e backup

Quando o usuário escolhe criar um backup, o aplicativo gera um arquivo local e o encaminha somente para o destino escolhido pelo próprio usuário no seletor do Android, como Google Drive, armazenamento local ou outro provedor disponível. Esse destino passa a ter sua própria política de privacidade.

Backups protegidos por senha são criptografados no aparelho antes da exportação. A senha não é armazenada pelo aplicativo. Se a senha for perdida, o backup protegido não poderá ser restaurado.

## Permissões

O scanner de documentos é iniciado por um componente do Android/Google Play Services. O Meu Ponto não solicita acesso amplo à galeria ou ao armazenamento; arquivos são escolhidos pelo seletor do sistema quando o usuário inicia uma importação ou exportação.

## Exclusão

O usuário pode apagar comprovantes pelo próprio aplicativo e pode remover os arquivos exportados no destino escolhido. Como os dados principais ficam no aparelho, desinstalar o aplicativo remove o espaço privado associado a ele, salvo cópias ou backups que o usuário tenha exportado.
